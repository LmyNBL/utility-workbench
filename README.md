# utility-workbench

Personal utility notes, small scripts, and configuration helpers.

This repository is intentionally safe for public storage:

- no node subscriptions
- no proxy server credentials
- no UUIDs, passwords, tokens, or private endpoints
- no generated runtime configuration containing secrets

Current contents are neutral helper files for building local configuration overlays. Sensitive values should stay on the target machine and be supplied through environment variables or local-only files.
